# Art Packs

Maelstrom's own character and creature art, as optional downloads. Each pack is
one `.kpack` file, read where it is (nothing is unpacked):

- **Monsters**: a portrait and a token for each creature. A creature with no
  picture of its own takes the one of its kind.
- **Fantasy Characters**: portraits and tokens by race, class and gender for
  the fantasy games, and the faces of people in any game (a guard, a goblin
  chief).
- **Sci-fi Characters**: the same for science fiction games.
- **Horror & Modern Characters**: the same for horror and modern games.

The Windows installer's **Art packs** page downloads the ones you tick into
this folder. You can also get them from Maelstrom's start screen (**Art
packs**), or download them from the
[art-packs release](https://github.com/krakenunbound/maelstrom-vtt/releases/tag/art-packs)
and put them here yourself.

Maelstrom reads this folder when a campaign starts; one added while a
campaign is running shows after **Folders > Refresh**. Taking a pack out
takes its pictures away from the pickers. A character that already uses one
of its pictures shows a letter until the pack is back.

Copy this folder to another computer and the art comes along.
