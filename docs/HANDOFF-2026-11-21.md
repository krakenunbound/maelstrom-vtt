  `fgMaps.cjs` now reads walls/lights/masks in image coordinates
  (`at()` subtracts the picture layer's place `baseAt`), pins/tiles/text by

2. **The remaining FG map settings** (the GM said "Yes, build them"). Surveyed
   across all 189 packs (script pattern: scan each `.kpack`'s `records.json`
   image records). Each needs reading in `fgMaps.cjs` and doing in MVTT:
   - `distancebaseunit` (77 maps, mostly `"10"`): FG's distance per square.
     MVTT reads only the record's `scale` ("10ft") and else assumes 5 ft, so
     these measure wrong. Use it for `grid.distance` when there is no `scale`.
     Quick and the most important.
   - `tokenlock` (`"on"` = players' moves wait for the GM): set the scene's
     movement lock (MVTT has it: `kraken_line_of_sight lockMovement`).
   - `allowplayerdrawing` (212 maps `"on"`): MVTT has no per-map player-drawing
     switch yet; add one (map setting, the drawing tools refuse players when off)
     and read it.
   - Text layers' `uselighting: true` (130): FG darkens that text with the map.
     MVTT draws labels above `<Lighting>` in `src/table/MapView.tsx` (around the
     `overlay labels` svg); add a label flag `lit` and draw lit labels under the
     lighting (or hide them in the dark for players).
   - Picture layers' `uselights: "false"` (3, Golden Grain Inn in N1): that layer
     ignores lighting; tiles are drawn by `tileLayer("below")` under the
     lighting; add a tile flag and draw such tiles above it.
   - `linkscale` (2): the zoom FG opens the map at; `previewvision` (2): FG opens
     it with the GM's player-vision preview on (MVTT has preview mode).
   Add each to `scripts/check-fg-classic-maps.mjs` as the others were.
3. **Party sheet members**: with Mira on the tracker the party sheet listed no

## Standing rules learned this session (also in memory)

- If imported content uses something MVTT lacks, build it into MVTT; never just
  report it as unsupported (`feedback-import-gaps-build-them`).
- The core is never written for one game; rulesets declare (manifests).
- FG layout may be followed; icons and art are always our own.
- After a rebuild, close the dev window and open a fresh one on the left monitor
  (`KRAKEN_WINDOW_AT=-2500,40`); kill stray dev Electron processes first, or the
  agent tools talk to the old one.
- A popped-out map window is a separate OS window: `kraken_ui_screenshot` shows
  only the main window.
